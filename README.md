
# Brew & Bean Cafe ☕

A modern, responsive cafe website designed to create an inviting online experience for cafe customers.

## 🌐 Live Demo

[Visit Brew & Bean Cafe](https://elaborate-biscotti-be31db.netlify.app)

## ✨ Features

- Responsive design for mobile and desktop
- Modern cafe-themed user interface
- Menu section showcasing cafe offerings
- About section
- Contact form
- Google Maps integration
- WhatsApp contact button

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5.2

## 📁 Project Structure

- index.html – Website structure
- style.css – Website styling
- script.js – Interactive functionality
